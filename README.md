# مِرْقاة — مساحة مذاكرة الصف الحادي عشر العلمي

موقع عربي تفاعلي يعمل مباشرة في المتصفح، ومتوافق مع الكمبيوتر والجوال.

## المزايا

- اختيار المادة ثم الوحدة ثم الدرس.
- شرح مختصر وملخصات وأسئلة نهاية الدرس.
- تطبيقات عملية ومحاكاة في التفاعلات الكيميائية والحركة ومعالجة البيانات.
- اختبار لكل درس واختبار في نهاية كل وحدة، وثلاثة نماذج تدريبية إلكترونية لكل مادة.
- مؤثرات صوتية اختيارية، مؤقت تركيز، وحفظ تقدم المذاكرة في المتصفح.
- روابط إلى أرشيف امتحانات وزارة التعليم ومكتبة زاويتي وبوابتها التعليمية.

## التشغيل

افتح index.html في متصفح حديث. لا يحتاج الموقع إلى تثبيت أو خادم.

## توضيح المحتوى والامتحانات

الشرح والأسئلة التفاعلية في الموقع مواد تدريبية مختصرة، والنماذج الثلاثة من إنشاء الموقع وليست أوراق امتحانات وزارية أصلية. أسماء الوحدات مجموعات مراجعة تعليمية وليست نقلًا حرفيًا لفهرس كل طبعة. استخدم روابط وزارة التعليم وزاويتي للوصول إلى المصادر الرسمية.
