# مِرْقاة — مساحة مذاكرة للصفوف 10–12

موقع مذاكرة عربي يعمل مباشرة في المتصفح ومتوافق مع الجوال والكمبيوتر.

## المتاح

- اختيار الصف العاشر أو الحادي عشر أو الثاني عشر والفصل الدراسي.
- تحديد المواد الاختيارية وحفظ اختيار الصف والمواد في المتصفح.
- مواد أساسية حسب الصف، وبطاقات مراجعة وشرح وأسئلة للدروس المتاحة.
- اختبارات تفاعلية للدروس والوحدات وثلاثة نماذج تدريبية لكل مادة متاحة.
- تطبيقات تعليمية ومحاكاة في موازنة معادلة كيميائية، وحساب السرعة، وتنظيم البيانات.
- رزنامة شخصية تضيف فيها مواعيد الامتحانات والإجازات، محفوظة محليًا.
- روابط إلى مكتبات المناهج والامتحانات ووثائق التقويم الرسمية.

## التشغيل

افتح `index.html` في متصفح حديث. لا يحتاج الموقع إلى تثبيت أو خادم.

## ملاحظات المحتوى والتقويم

تختلف الكتب والمقررات حسب الصف والسنة واختيارات الطالب. بعض الدروس الحالية مراجعات تأسيسية وليست تغطية كاملة لكل وحدات الكتب. تحقّق من كتابك المعتمد وروابط الوزارة. نماذج الاختبارات داخل الموقع تدريبية وليست أوراقًا وزارية أصلية. الرزنامة شخصية؛ أضف المواعيد من مدرستك وتابع إعلانات الوزارة للتواريخ المعتمدة.
